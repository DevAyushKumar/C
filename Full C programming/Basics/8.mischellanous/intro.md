What is constant and literal ?
constant: Constant is a variable name where value cannot be changed after it has been initialized.

Note:
-> All constant variables must be provided in upper case.
-> In C language, we can declare a constant using constant keyword and #define preprocessive directive.

Literal:
Literal is a data or actual value.

Note:
In simple, literals are value and it can be any type like integer literal, float literal, character literal, etc.

1. Integer literal -> 10,20,30 etc.
2. Boolean literal -> true, false, etc.

What is tokens ?
-> A token is the smallest meaningful unit in C language.

token types:
-> Keywords
-> Identifiers
-> constant
-> string
-> Operator
-> Special symbols
