What is gets and puts in C progarmming ?
-> gets and puts function's are declared in the headerfile "stdio.h" both the functions are involved in the input/output operations of the string

gets:
-> gets functions is similar to scanf() but it is used to read only the caracters in string format. With double quotes and store in a character any format.

puts:
-> puts function is similar to printf() but it is used to display only string after reading by gets functions.
