What is type - casting ? Full explanation ?
-> Sometimes in our program, it is necessary to convert from one datatype to another, such as from a double to an int. This process of conversion is called type casting.

Typecasting can be peroformed in two ways
-> Implicit typecasting
-> Explicit typecasting

Implicit typecasting:
-> If we want to store small value into a bigger variable than we need to implicit type casting.

int -> long -> float -> double

Explicit typecasting:
-> If we want to store bigger value into a smaller variable then we need to use explicit typecasting.

int <- float <- double

Difference:
Implicit:
-> complier is responsible to perform
-> Also called widening/upcasting

Explicit:
-> programmer is responsible to perform 
-> Also called narrowdcasting/downcasting

What is a keyword ?
-> Keyword means "reserved words" with special meaning cannot be used on a variable name, function name.

Note:
-> Compiler already knows the keyword meaning.
-> It should be in lowercase
-> 32 keywords are there in C language
