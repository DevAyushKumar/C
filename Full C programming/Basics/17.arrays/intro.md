What is array ?
-> array is a collection of fixed-size sequence of similar datatypes staored at contiguous memory locations.

Note:
-> Elements of array stored in contiguous memory location.
-> Array index starts from zero (0)

syntax:
-> datatype arr-name[size]
-> datatype arr-name[size] = {val1, val2}
-> datatpye arr-name[] = {val1, val2}

Why use array ?
without array:
-> You need many variables (x,y,z..) 
-> Hard to manage
-> Memory not organized
With array:
-> you use only varaiable (arr[])
-> Easy to manage
-> Memory is continuous and efficient

Types of array:
-> one-dimensional 
-> two-dimensional 
-> multi-dimensional

1-D array:
-> This is the simplest form of an array stores list of data in a single row.

Common array operations:
-> Accessing of elements using index
-> Insertion
-> Deletion
-> Traversal

2-D array:
-> 2-D array looks like a table with rows and columns (matrix)
