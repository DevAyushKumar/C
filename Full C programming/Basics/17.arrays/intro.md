What is array ?
-> array is a collection of fixed-size sequence of similar datatypes staored at contiguous memory locations.

Note:
-> Elements of array stored in contiguous memory location.
-> Array index starts from zero (0)

syntax:
-> datatype arr-name[size]
-> datatype arr-name[size] = {val1, val2}
-> datatpye arr-name[] = {val1, val2}
