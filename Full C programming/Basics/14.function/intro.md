What is function ?
-> function is a self-contained block of code which is used to perform a specific task.

Why function ?
-> It breaks down a large task to smaller
-> It makes code simple, clean, reusable and easy to understand

Flow of function:
-> function dclaration 
-> function defination
-> function calls

Types of function:
-> Library function
-> user defined function

1. Library function:
A) It is ready made function 
B) It can be used without defining

2. user defined function:
These functions are created to organize the code, reuse and meet the needs of programmer.
