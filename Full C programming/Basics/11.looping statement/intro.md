Looping statement:
-> Someimtes we need to execute the block of code repeatedly while some condition evaluates true.

Types of loop:
-> for loop
-> while loop
-> do while loop

1. For loop:
-> When we use the for loop only when we exactly know the number of times to executly know the number of times to execute the block of code.

2. While loop:
-> while loop is also used to iterate statements multiple times but we use while loop when we don't know the number of iteration in advance.

3. Do while loop:
-> When the number of iteration is not known and we have to execute loop atleast once.
