What is comment ? 
-> A comment is actually not part of the program. It is added by developers to make code readable for other developers.

Types:
-> Single line (/)
-> Multi line (/* */)

What is identifiers ?
-> A name in c language is called identifier. It can be variable, function, structure, array, etc.

Note:
