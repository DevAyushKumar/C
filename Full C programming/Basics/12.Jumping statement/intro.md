Jumping statement:
-> Jump statements are used to trasfer the control of the program to the sepcific statements

Note:
-> They provide flexibility in managing program flow

Types:
-> break
-> continue
-> goto
-> break

A) Break:
-> Jump out of a loop or switch

B) Continue:
-> It skips the rest of loop interations and jump to the next iteration

C) goto statement:
-> goto statement sends control to a label in the program.

Note:
-> It should be used carefully, beacuse it can make code hard to read.

D) return:
-> When a function finishes its job, it returns control to the place it was calling from.
