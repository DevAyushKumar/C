Bubble sort:
-> Bubble sort arrange N elements of array by placing the biggest element on proper position.

algorithm:
step 1: begain
step 2: define an array
step 3: compare the 1st element with the 2nd element 
-> If the 1st element is greater swap them
-> Move to the next pair of elemets
step 4: continue comparing and swapping adjacent elements until the largest element "bubbles up" to the end of the array in the 1st pass
step 5: repeat the same process for the remaining unsorted array elements.
step 6: exit
