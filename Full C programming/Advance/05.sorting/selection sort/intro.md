Selection sort:
-> Selection sort arrange N elements of array by placing the smallest item in proper position in case of ascending order arrangement.

Algorithm:
Step 1: begain
step 2: find the smallest element of array
step 3: swap the smallest number with the 1st number in the list
step 4: repeat for the rest
step 5: swap again with newely found elements
step 6: keep repeating
step 7: done sorting
step 8: exit
