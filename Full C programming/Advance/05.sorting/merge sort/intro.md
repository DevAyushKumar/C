Merge sort:
-> Merge sort is a sort algorithm that split the items to be sorted into two groups recursively, sort each group and merges them into a final sorted sequence.

algorithm:
step 1: begain
step 2: divide all the items of array in two item pairs. If single item remain make it single group
step 3: sort each of the pair
step 4: merge two pairs into a single pair
step 5: sort the merge pair
step 6: repeat the above steps until all the elments of array are not sorted
step 7: exit
