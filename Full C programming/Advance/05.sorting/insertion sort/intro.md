Insertion sort:
Insertion sort arrange N elements of array by inserting particular item in a particular place way that the items are in sorted array.

Algorithm:
step 1: Begain
step 2: starts with 2nd element of the array
step 3: compare and shift if the current element is smaller
step 4: place the current element in its current sorted position within the shifted portion.
step 5: move to the next unsorted element and repeat step 3 and 4 until all elements are sorted
step 6: exit
