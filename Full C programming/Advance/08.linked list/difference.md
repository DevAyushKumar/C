Array:
-> Array is a collection of homogenous (similar) datatype
-> array elements are stored in continous memory location 
-> array work with static data structure
-> array elements are independent to each other
-> array takes more time
   ex:
   insertion , deletion, etc.

linked list:
-> linked list is a collection of node (data and address)
-> linked list elements can be stored anywhere in the memory 
-> linked list work with dynamic data structure
-> linked list elements are dependent to each other
-> linked list takes less time
   ex:
   insertion, deletion,etc
