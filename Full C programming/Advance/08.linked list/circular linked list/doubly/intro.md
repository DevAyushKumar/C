Circular doubly linked list:
-> If a last node of doubly linked list hold the address of first node and first node holds the address of last node called circular doubly linked list

Algorithm:
-> insert/delete at beginning
-> Insert/delete at ending
-> Insert/delete at any position

WAP for backword traversing of circular doubly linked list:
step 1: begain
step 2: set i <- last
step 3: print data[i]
step 4: i <- previous
step 5: goto step 3 until i != last
step 6: exit

WAP to forward traversing of circular doubly linked list:
step 1: begain
step 2: set i <- print
step 3: print data[i]
step 4: i <- next[i]
step 5: goto step 3 until i != first
step 6: exit
